# Аудит расходов

## Описание

Скилл анализирует файл с расходами (CSV или Excel) и находит:

- **общую сумму** расходов (точную, без округлений);
- **разбивку по категориям**, отсортированную по убыванию;
- **топ-5 самых крупных трат**;
- **дубликаты** — повторяющиеся платежи (одинаковые дата, описание и сумма);
- **аномалии** — суммы, сильно выбивающиеся из своей категории;
- **отрицательные суммы** (возвраты, корректировки).

По итогам скилл готовит **краткую сводку для владельца** простым языком:
что не так, на что обратить внимание, где возможны проблемы.

Скилл **не привязан к конкретному файлу**: принимает любой файл с расходами,
а скрипт `audit.py` **сам определяет** нужные столбцы (дата, категория, сумма,
описание) по названиям заголовков — на русском или английском, в любом порядке.

## Как использовать

Пользователь даёт **путь к файлу** (например, `data/costs.xlsx`) или **URL**
(ссылку на CSV). Файл может называться как угодно и иметь любые названия колонок.

## Что делать

1. **Получить файл.**
   - Если дан URL — скачать файл (например, `curl -s -o input.csv "<URL>"`).
   - Если дан путь — использовать его напрямую.

2. **Запустить `audit.py` с этим файлом:**
   ```
   python audit.py <путь_к_файлу>
   ```
   Скрипт сам определит столбцы и посчитает все показатели.
   Для Excel-файлов нужен пакет `openpyxl` (`pip install openpyxl`).

3. **Прочитать результат** из созданного файла `report.txt`
   (там полный отчёт по всем шести пунктам).

4. **Написать краткую сводку для владельца** на основе `report.txt`:
   - что не так с расходами;
   - на что обратить внимание в первую очередь;
   - где возможны проблемы (двойные оплаты, подозрительно крупные траты,
     платежи без категории, возвраты);
   - простым языком, без технических терминов, с конкретными суммами.

5. **Показать сводку пользователю** и предложить следующий шаг
   (сохранить отчёт, проверить конкретные операции и т.п.).

## Формат входного файла

Минимально нужен **столбец с суммой**. Желательны также столбцы даты,
категории и описания — тогда отчёт будет полным. Скрипт распознаёт, в частности,
такие названия заголовков:

| Роль       | Примеры названий столбца                                  |
|------------|-----------------------------------------------------------|
| Дата       | date, дата, день, число, период                           |
| Категория  | category, категория, тип, вид, статья, группа             |
| Сумма      | amount, сумма, стоимость, цена, price, total, расход       |
| Описание   | description, описание, наименование, назначение, комментарий |

## Файлы скилла

- `audit.py` — скрипт анализа (стандартная библиотека Python; `openpyxl` только для Excel).
- `SKILL.md` — это описание.
- `report.txt` — создаётся при запуске, содержит полный отчёт.
